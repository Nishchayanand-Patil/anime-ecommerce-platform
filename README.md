### 🔗 **[View Live Project Here](https://otaku-sable.vercel.app)** 🔗

OtakuVault is a fully responsive, highly optimized e-commerce frontend built for anime and manga enthusiasts. It features a sleek "neon-dark" aesthetic, performant animations, simulated Razorpay checkout, and seamless catalog filtering.

---

## ✨ Features

- **Immersive Design:** Custom dark/neon UI with `Space Grotesk` and `Inter` typography, glassmorphism, and fluid `motion` animations.
- **Optimized Performance:** Implements React `lazy()` and `<Suspense>` for code-splitting, along with memoized components (`React.memo`, `useMemo`) for blazing-fast renders.
- **E-Commerce Flows:** Fully functional client-side Cart & Wishlist state management using context/zustand patterns.
- **Secure Architecture:** Pre-configured with secure HTTP headers (`X-Frame-Options`, `X-Content-Type-Options`) and lazy loading (`decoding="async"`) for images.
- **Hosting-Ready:** Includes routing configuration for Vercel (`vercel.json`) and Netlify (`_redirects`) out of the box so page refreshes never break the router!

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/otakuvault.git
   cd otakuvault
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run the Development Server:**
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack

- **Framework:** React 18 (Vite)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4)
- **Animations:** Motion (Framer)
- **Icons:** Lucide React
- **Routing:** React Router v6
